📝 To-Do List Manager (Python)

A simple command-line To-Do List application built using Python and lists.

 🚀 Features
1. Add tasks
2. Remove tasks
3. View all tasks
4. Simple and user-friendly menu

 🛠️ Technologies Used
1. Python
2. List(Data Structure)

 ▶️ How to Run
1. Clone the repository
2. Open terminal in project folder
3. Run:
   python main.py

📌 Example
--- TO-DO LIST MENU ---
1. Show Tasks
2. Add Task
3. Remove Task
4. Exit

💡 Concepts Used

1. Functions
2. Loops (for, while)
3. Conditional statements (if-else)
4. List operations (append, pop)
